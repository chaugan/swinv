# Audited exceptions to the licence gate.
#
# `go-licenses` classifies a dependency by pattern-matching its LICENSE file.
# A few projects ship a permissive licence in prose that the classifier does not
# recognise, and reports as "Unknown". Listing a module here records that a
# human read the actual licence text and confirmed it is permissive.
#
# SCOPE OF THIS FILE - read before adding an entry:
#   * An entry ONLY suppresses an "Unknown"/undetected classification.
#   * It does NOT and MUST NOT suppress a detected GPL, AGPL, or LGPL licence.
#     `make license-check` fails on those regardless of what is listed here.
#   * Every entry must name the licence found and where it was read from.
#
# Format: <module path> <SPDX-ish licence> <justification>
